# CForex → CFIP capability continuity

CForex v0.9.154 is a capability reference for CFIP-PRO, not a code migration target. Its documented Python-first architecture, deterministic analysis, governed learning, data lineage, chart-first terminal, release gates, research fabric and fail-closed AI boundaries are preserved as contracts and clean-room modules.

## Carried-forward capabilities

- Chart-first professional terminal.
- FVG lifecycle/state, order blocks, liquidity, displacement, premium/discount and market structure.
- Multi-timeframe canonical analysis.
- Broker-aware risk and position sizing.
- Journal, outcomes, attribution and calibration.
- Replay and deterministic evaluation.
- Research Intelligence Fabric with provenance and point-in-time evidence.
- Elyrava as a governed intelligence layer; AI cannot directly mutate production.
- Sandboxed autonomous research/development with explicit promotion.
- Dataset/source freshness and rights governance.
- Release gates, auditability, observability and rollback.
- i18n/RTL/LTR and terminal-native education.
- No direct SQL from AI agents and no unrestricted production mutation.
- Modular boundaries before premature microservices.
